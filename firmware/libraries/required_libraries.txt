# Required Libraries for Arduino IDE

1. ESP8266WiFi
   - Install via Board Manager: ESP8266 by ESP8266 Community

2. ThingSpeak
   - Library Manager: ThingSpeak by MathWorks

3. Servo
   - Built-in Arduino library

4. SoftwareSerial
   - Built-in Arduino library

# Installation Steps:
# 1. Open Arduino IDE
# 2. File -> Preferences -> Additional Boards Manager URLs
#    Add: http://arduino.esp8266.com/stable/package_esp8266com_index.json
# 3. Tools -> Board -> Boards Manager -> Install "ESP8266"
# 4. Sketch -> Include Library -> Manage Libraries
# 5. Search and install "ThingSpeak"
